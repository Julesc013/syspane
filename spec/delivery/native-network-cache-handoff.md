calibration establishes all ten digits, decimal point and null dash before real
values are rendered. Raw documents are independently checked against native counter
brackets and the shared projection, then the entire displayed strings are decoded
from root-window pixels. The wrong-value control cannot define its own expected
result. Existing native composition and post-disable marker checks remain required.

Policy denial wins before payload parsing. Native cases also reject a pre-grant
frame, older/conflicting policy, invalid generation, extra key, zero/duplicate frame
sequence and stale-revision replay. Equal grants are idempotent. An oversized rate
clears the entire cache with a capacity result; no partial field prefix survives.
New grants clear the old cache and require an explicitly selected new full.

Local `cleared` acknowledges removed payload references and actors; visible clearing
is established separately by captures after the 200 ms deadline. This does not claim
secure memory wiping or sanitization of compositor buffers. Public state contains
counts and policy/sequence status only. All operational digits, source documents,
raw private receipt journals and their pixel crops stay in owned ignored files.
