# Collection table surface checkpoint

Source baseline: `733234ef7e1b8a77f6139f3a9008e46949168af4`. Git history identifies
the resulting commit. The [package](packages/w-09-table-surface.md) extends W-09's
existing owner with actual native collection tables using scene/binding identities
already present. Ordered fields become columns; scoped producer/epoch/entity keys
and snapshot generation align cells independently of source arrival order or sort.
Typed rows and cell rectangles remain inside the synchronous policy-owned frame.

The grid measures headers and every cell, uses exact scaled gaps, and supplies its
readable extent to common scene layout. Exact scalar values and state axes remain.
Truncation shows selected and total row counts. Missing cells keep their row; an
incomplete column suppresses partial table data. Capacity or unsupported content
returns the explicit whole-scene alternative. High contrast and a single background
application preserve readable colors and translucent composition.

## Evidence and corrections

Fourteen original table families and independent native grid expectations were
archived before implementation. The original table component and external-window
checks failed while both scalar checks passed. The implementation passes those
families; additional cases verify the 256-cell budget and 3/2-scale geometry.

The observer's former set_cache_mask call on a child object emitted an AT-SPI
assertion. Moving the optional setting to the application object produced two
preserved 35-second observer timeouts. That setting was removed; explicit cache
clearing before traversal/name reads remains. The [upstream API description](https://gnome.pages.gitlab.gnome.org/gtk/atspi2/method.Accessible.set_cache_mask.html)
identifies this setting as an application-level testing workaround. These native
timeouts remain observer failures, not evidence of a renderer qualification.
The outer runner now retains timeout streams and kills only its newly owned
process group. Reference rasters are prepared before stimulus; observations still
start at acknowledgement and retain the original 200 ms limit.

The independent experiment renders a two-column/two-row table with public synthetic
values. Fixed expected text is measured separately, then composed by the observer's
own grid algorithm. External X root pixels and complete accessible names (with only
changing numeric age normalized) are checked for initial/replaced values, revoke,
stale delivery, regrant without data, fresh attachment and retained source loss.
The deliberate old-pixel and old-name controls must fail the relevant erasure
observation. Every original scalar family and native control remains exercised.

`out/evidence/w-09-table-attempts.json` binds source/oracle archives,
failed and passing attempts, raw native observations and exact artifact/runtime
identities. The machine handoff is `table-handoff.json`; `w-09-table-staging.json`
verifies final staged inputs. Ephemeral X authorization cookies are never archived.
Linux receives a complete regression run. Windows configure/inventory checks verify
the Linux-only target guards; previous Windows test results remain historical and
are not claimed as new executions. Specification checks retain the existing two
Windows symlink skips. No dependency was installed or redistributed.
