# Native unset, property dispatch and retained deferred calls

The source-bound [checkpoint](checkpoints/gtk-unset.json) separates public cache,
inherited widget-unset and widget-property notification dispatch from complete
commands. Instrumentation forwards each original slot with its unchanged object/
parameters and restores the slots after owned teardown. Native events are retained;
private toolkit fields and foreign processes are untouched. The
[package](packages/w-11-gtk-cell-lifetime.md) closes each experiment before execution.

## Measured retirement

The external cases retain 6344 native/wire cells from 3172 exact initial rows.
The retired root, expanded/collapsed chart, exact active/fresh values, seven wire
methods, old-path non-reuse and actual native exit remain mandatory. Each case
records 88816 raw old-reference requests, with verified withdrawal distinct from
successful empty data. Every original cell has exactly one normal defunct event
and its native text/name/count/layout remains empty after retirement and regrant.

| Cohort/heavy command | Complete callback | Cache slots | Inherited unset | Widget dispatch |
| --- | --- | --- | --- | --- |
| Collapsed | 313.108 ms | 30.97 ms | 129.7 ms | 124.241 ms |
| Expanded | 307.603 ms | 31.211 ms | 126.475 ms | 123.578 ms |

Each measured slot reaches depth one. These are component clocks; the original
complete clock and remaining unmeasured work remain. Do not infer a general
performance pass or replace normal lifecycle events to fit the original budget.

The first expanded case fails during initial SDK Text-interface lookup before any
retirement command; its source, transcript and partial journal are preserved.
Collapsed collection passes. A later collector adds bounded row/column/reference,
completed-cell/live-process and raw text/name/count diagnostics only on such a
failure; every original initial assertion remains. Later passes do not establish
the first failure's cause or erase it.

The native-only control uses the same prototype/data/cell holds/getter families,
explicitly priming native word/layout reads before readiness. NO_AT_BRIDGE=1 is
confined to that diagnostic. Expanded erasure is about 35 ms and collapsed
retirement about 32 ms. Native controls pass with normal exit and exactly-one
defunct counts. They are explicitly wire_qualified false and
performance_qualified false; the product and required qualification keep the
bridge enabled. This comparison does not prove every underlying library cost.

## Deferred-call control

The test-only FIFO retains exact cells/parents/parameter specifications, erases
and checks native cache data before queued notification drainage, then invokes
every original call once in order. Queue capacity is 16384 and each property array
at most 8. References are released after use. Complete held-native/wire/lifecycle
checks pass after all original calls, including checks again after drainage.

| Cohort/heavy command | Preparation | Queued calls | Drain time | Largest 64-call slice | Complete command |
| --- | --- | --- | --- | --- | --- |
| Collapsed | 36.492 ms | 12684 | 264.431 ms | 4.593 ms | 303.23 ms |
| Expanded | 40.037 ms | 12556 | 262.717 ms | 3.605 ms | 304.726 ms |

This control is synchronous. Slices are not GUI callbacks and the full original
command still exceeds 100 ms. It proves that late original calls can preserve
this owned-window lifecycle/data oracle; it does not qualify asynchronous ownership,
destroyed-parent behavior, production shutdown or unmeasured GUI work.

The public slot definitions are
[GtkAccessible](https://raw.githubusercontent.com/GNOME/gtk/3.24.41/gtk/gtkaccessible.c)
and [GtkCellAccessible](https://raw.githubusercontent.com/GNOME/gtk/3.24.41/gtk/a11y/gtkcellaccessible.c).
Native execution evidence, not source inspection alone, determines eligibility.
