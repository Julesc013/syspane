# Native conditional presentation checkpoint

Source baseline: 529c39bff13b10bbddfb8b2defb449ba1517c5a0. The
[package](packages/w-09-native-visibility.md) and exact text/presentation examples
were frozen before production changes; both retain their original bytes.

## Implemented boundary

SceneSurface measures authorized unconditioned content and resolves layout before
consuming the shared borrowed visibility tree. Hidden content keeps its node and
bounds while its native payload, fonts, pixels and inspector row disappear.
All seven primitive kinds participate. Authorized bounded chart/image work continues
while hidden; policy revocation still erases frame, history and image ownership.

Unresolved rules and mandatory source states become status-only diagnostics.
Groups relay warnings to descendant leaf bounds; diagnostic descendants of hidden
groups retain stable inspector keys. Warning wrapping uses existing pixel bounds
and native metrics. Overflow or warning overlap returns surface.visibility_layout;
ordinary content cannot overpaint diagnostics. No separate decision cache is added.

The explicit trusted SurfaceConfig.experimental_visibility option defaults false.
Existing refusal tests still pass, and ordinary editor/installed paths do not set
it. Native rule controls, selection/gesture behavior and their durable integration
remain required before general enablement. This is a Linux component experiment,
not a completed conditional-editing feature or complete release edition.
